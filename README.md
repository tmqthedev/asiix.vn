# 🎵 asiix.vn - Official Website

Website chính thức của nghệ sĩ **asiix** - được xây dựng với **Astro** và tối ưu hóa cho **Vercel**.

## 🌐 Website Features

- **Trang chủ:** Hero với YouTube background video
- **Profile:** Thông tin nghệ sĩ (CONGB)
- **Discography:** Danh sách album
- **Gallery:** Thư viện ảnh với lightbox
- **Video:** YouTube video embed
- **Responsive:** Mobile-first design
- **Performance:** Optimized images & videos
- **Security:** CSP headers & security best practices

## 🚀 Quick Start

### Prerequisites
- Node.js >= 18.0.0
- npm >= 9.0.0

### Development

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Open http://localhost:3000
```

### Build & Preview

```bash
# Build for production
npm run build

# Preview production build
npm run preview
```

## 🚀 Deployment

### Deploy to Vercel (Recommended)

```bash
# 1. Push to GitHub
git add .
git commit -m "Ready for deployment"
git push origin main

# 2. Connect to Vercel
# - Go to https://vercel.com
# - Sign in with GitHub
# - Click "Add New Project"
# - Select asiix.vn repository
# - Click "Deploy"

# 3. Setup custom domain (optional)
# - Vercel Dashboard → Domains
# - Add asiix.vn
# - Update DNS nameservers
```

✨ **That's it! Your site is live!**

### Alternative: Deploy to Netlify

```bash
# Netlify has netlify.toml config already setup
# Just connect your GitHub repository at https://netlify.com
```

### Setup Custom Domain

1. **Connect domain in Vercel:**
   - Project Settings → Domains → Add Domain
   - Enter `asiix.vn`

2. **Update nameservers at domain registrar:**
   ```
   ns1.vercel-dns.com
   ns2.vercel-dns.com
   ns3.vercel-dns.com
   ns4.vercel-dns.com
   ```

3. **SSL certificate:**
   - ✅ Auto-generated by Vercel (Let's Encrypt)
   - ✅ HTTP → HTTPS automatic redirect
